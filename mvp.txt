Open Source Radar
Product Vision

Most GitHub discovery is terrible.

People find projects through:

GitHub Trending
Hacker News
Reddit
X/Twitter
YouTube

The problem is these are reactive.

By the time a project appears everywhere, you're already late.

Open Source Radar should answer:

Which repositories are gaining momentum right now, why are they growing, and are they likely to become important?

Think:

Bloomberg Terminal for open source
Crunchbase for repositories
SimilarWeb for developer ecosystems

What Makes It Interesting

The real value is not:

This repo has 50,000 stars.

The value is:

This repo is growing faster
than 99% of repositories
in its category.

That requires:

historical data
ranking algorithms
trend detection

Those are substantially more interesting engineering problems than another CRUD SaaS, while still producing something that looks and feels like a polished product.
